Embed GoodData dashboards in your application with the `Dashboard` component, and extend them with plugins: custom widgets, replaced renderers, drill handlers, and automation dialogs. The `Dashboard` component can also open [Analytical Designer](../analytical-designer/) on top of the dashboard, so users explore, edit, and create visualizations without leaving it. The hooks in this section let plugin code read dashboard state, dispatch commands, and read widget data.

Start with [Dashboard plugins](dashboard-plugins/) for the concepts, then [develop your first plugin](develop-your-first-plugin/).
