Embed GoodData dashboards in your application with the `Dashboard` component, and extend them with plugins: custom widgets, replaced renderers, drill handlers, and automation dialogs. The hooks in this section let plugin code read dashboard state, dispatch commands, and read widget data.

Start with [Dashboard plugins](dashboard-plugins/) for the concepts, then [develop your first plugin](develop-your-first-plugin/).
