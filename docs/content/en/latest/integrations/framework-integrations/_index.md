GoodData.UI ships as React components, but you don't need a React app to use it. These guides add GoodData to other frameworks, either by wrapping the React components or by embedding the framework-agnostic [Web Components](../web-components/web-components-overview/).

Any JavaScript or TypeScript framework can embed GoodData through Web Components. For SvelteKit, see the [frontend integration series blog post](https://www.gooddata.ai/blog/frontend-integration-series-sveltekit/).
