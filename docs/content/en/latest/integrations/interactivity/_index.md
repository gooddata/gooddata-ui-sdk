These pages cover how a visualization behaves once it's on the page: what happens when someone clicks into a data point, how you find out that an export or a legend finished rendering, and how you swap in your own loading and error UI. Each topic maps to a specific callback or component prop, so pick the one that matches the behavior you need to hook into.

This is a different concern from choosing *what data* a visualization shows in the first place — for attribute, date, measure-value, and ranking filters, see [Filters](../../filters/).
